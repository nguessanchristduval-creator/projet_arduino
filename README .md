# Projet Arduino — Capteur de température et d'humidité

Programme Arduino qui mesure la température et l'humidité de l'air à l'aide d'un capteur DHT11, et affiche les valeurs relevées.

Projet réalisé dans le cadre de ma première année de Bachelor Informatique et Systèmes Digitaux à l'EPSI.

## Matériel utilisé

- Une carte Arduino
- Un capteur de température et d'humidité DHT11
- Câbles de connexion

## Bibliothèques nécessaires

Ce projet utilise la bibliothèque **DHT sensor library** (Adafruit), à installer depuis le gestionnaire de bibliothèques de l'IDE Arduino.

## Fonctionnement

1. Ouvrir le fichier `Arduino_projet2.ino` dans l'IDE Arduino
2. Brancher le capteur DHT11 à la carte Arduino
3. Installer la bibliothèque DHT si nécessaire
4. Téléverser le programme sur la carte
5. Ouvrir le moniteur série pour voir la température et l'humidité affichées
